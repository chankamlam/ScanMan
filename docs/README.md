## 目录里的其他资产

| 路径 | 说明 |
|------|------|
| `check_all.bat` | 一键跑「环境自检 → 44 项单元测试 → 冒烟训练 → 批量推理」，约 40 秒 |
| `test_cases/test_preprocess.py` | 44 项预处理断言（清洗 / 截断 / CWE 规范化 / 防泄漏划分 / 标签映射） |
| `test_cases/detection_test_cases.jsonl` | 10 条人工写的检测用例（6 漏洞 + 4 安全，含 3 组正负对） |
| `test_cases/classification_test_cases.jsonl` | 7 条分类用例（覆盖高频 CWE，跨 C/PHP/Python） |
| `test_cases/out_detection*.jsonl` | 批量推理的实测输出，用于看输出格式 |

> ⚠️ **人工用例只有 10 条，别拿它当验收标准。**
> 真正的测试集是 `data/processed/cvefixes_detection_test.jsonl`（**1,902 条**），
> 用 `python scripts/evaluate.py --input ... --sweep` 评估。
> 那 10 条是"人眼看得懂的小抄"，用来快速看输出格式和直观感受，不用于统计。

## 最快的验证方式

```bat
cd /d <项目根>\vuln_bert
docs\check_all.bat
```

约 40 秒后应该看到：

```
[ OK ] ... 环境自检全绿
通过 44 项，失败 0 项 / 全部通过
训练完成 ✅
与 gold 标签对比准确率: ... (冒烟模型，数字没意义)
ALL CHECKS PASSED
```

> 最后那个准确率是**冒烟模型**（64 条样本训 1 轮）的成绩，数字没有意义，
> 它只证明"数据能读、模型能建、能训练、能保存、能加载、能推理"这条链路是通的。
